# declick

Generated by declick. Turns anything into a CLI so agents stop clicking. Every command returns `{"ok":true,"data":...,"meta":{"count":N,"truncated":false}}` on success and `{"ok":false,"error":"...","exit":N}` on failure (JSON is the default when piped; add `--json` to force it). Exit codes: 0 ok, 1 error, 2 not found, 3 blocked by governance or an unarmed desktop, 4 auth needed.

Start here:

```
declick doctor                      node, home, PATH, deskclaw, claude, vault, engines
declick list                        every adapter with verbs, auth keys, last run
declick describe <name> --full      one adapter's verbs, args and flags
declick run <name> <verb> ARGS      invoke a verb (works without ~/.declick/bin on PATH)
```

Build:

```
declick add spec.json --name NAME [--verbs a,b | --tag t]      OpenAPI file or https://.../openapi.json
declick add app:"Window Title" --name NAME --goal "..." --verb V   Claude authors a desktop verb (needs: declick desk arm 15)
declick add app:"Window Title" --name NAME --recipes DIR|FILE|-   hand-written recipes
declick auth NAME                   which env keys are missing and where they are read from (exit 4 if any)
```

Inspect and fix:

```
declick status [NAME]               last run, last error with tree diff, proposals, recipes
declick manifest NAME [--verb V]    the compiled contract (http method/path or recipe steps)
declick repair NAME VERB            re-author a verb whose element path stopped resolving
declick proposals NAME | declick accept NAME VERB   rejected authoring proposals, promote one
declick recipes NAME | declick recipe NAME VERB     stored desktop recipes
declick lint NAME | declick build NAME | declick skill [NAME]
declick remove NAME [VERB]          deletes manifest, launcher and SKILL.md (or one verb)
declick export NAME > bundle.json | declick import bundle.json
declick desk status | arm 15 | disarm
declick path --install              put ~/.declick/bin on PATH for new shells
```

Flags every generated verb accepts: `--json`, `--fields a,b`, `--limit N`, `--dry-run` (mutating verbs), `--help`. Both `--flag value` and `--flag=value` work; boolean flags never eat the next argument. Unknown flags are an error, not ignored.
